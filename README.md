📌 Project Title

Fisheye Menu for Usability Heuristics (HCI Project)

📖 Description

This project implements an interactive Fisheye Menu as part of a Human-Computer Interaction (HCI) assignment.

A fisheye menu displays all items simultaneously, but dynamically enlarges the item under focus, providing more details while maintaining context.

The system is designed to present the 10 Usability Heuristics in an intuitive and visually responsive way.

🎯 Objectives
Implement a fisheye menu interaction technique
Enhance usability through focus + context visualization
Provide progressive disclosure of information
Apply UI/UX design principles in a web environment

🧠 Key Features
✅ 10 interactive menu items (UH#1 – UH#10)
✅ Hover/click-based enlargement (fisheye effect)
✅ Dynamic scaling of focused item
✅ Display of detailed heuristic information
✅ Smooth animations and transitions
✅ Icon + label-based navigation
📚 Usability Heuristics Covered

The menu represents the following usability heuristics:

Visibility of System Status
Match Between System and Real World
User Control and Freedom
Consistency and Standards
Error Prevention
Recognition Rather Than Recall
Flexibility and Efficiency of Use
Aesthetic and Minimalist Design
Help Users Recognize, Diagnose, Recover from Errors
Help and Documentation

⚙️ How It Works
All 10 menu items are displayed simultaneously
When a user hovers or clicks on an item:
The item enlarges (fisheye effect)
Additional details appear (e.g., “Error Prevention”)
Other items shrink proportionally
This maintains context while emphasizing focus
